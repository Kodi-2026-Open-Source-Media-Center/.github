# Project Overview

Kodi is a free and open-source media center designed for organizing and playing video, music, podcasts, photos, and other digital media from local, network, and supported online sources.

Its television-oriented interface is designed for large screens and remote controls, while skins, add-ons, profiles, and configurable libraries allow the experience to be adapted to different setups. Kodi runs on Windows, Linux, Android, Raspberry Pi, macOS, iOS, tvOS, and webOS.

---

# Video & Movie Library

Kodi can organize personal video collections into a structured media library.

Movies and TV shows can be displayed with artwork, descriptions, genres, actors, seasons, episodes, and other metadata when available from configured sources.

Kodi supports a wide range of video formats and can work with media stored locally or on network storage.

---

# Music & Audio

Kodi also provides a dedicated music library for organizing albums, artists, genres, playlists, and other audio content.

The application supports numerous audio formats and provides playback controls designed for both desktop and television environments.

Music collections can be combined with artwork and metadata to create a browsable media-center interface.

---

# Network & Streaming

Kodi can access supported media stored on network shares and other compatible network services.

SMB, NFS, UPnP, WebDAV, and other supported protocols can be used depending on the platform and configuration.

Kodi 22 development has included improvements to SMB stability and performance, NFS handling, HTTP/HTTPS access, WebDAV paths, and UPnP functionality.

---

# Add-ons & Customization

Kodi uses an extensive add-on ecosystem to expand its capabilities.

Add-ons can provide additional media sources, interface features, metadata providers, subtitles, visualizations, remote-control functionality, and other integrations.

Skins can also change the appearance and layout of Kodi's interface.

Kodi's official site currently lists more than **1,000 official add-ons**.

---

# Games, PVR & Remote Control

Kodi includes support for gaming features, including emulators and compatible game controllers.

PVR functionality can be used with compatible backend systems for live television, recordings, channel groups, and electronic program guides.

The application is designed around a 10-foot interface, making it suitable for televisions and remote-control-based environments.

# System Compatibility & Performance

| Component        | Minimum Practical Configuration                         |
| ---------------- | ------------------------------------------------------- |
| Operating System | Windows, Linux, Android, macOS, iOS, tvOS, webOS        |
| Processor        | Modern dual-core CPU                                    |
| Memory           | 2 GB RAM minimum; 4 GB+ recommended                     |
| Storage          | 200 MB+ for the application                             |
| Graphics         | Hardware video acceleration recommended                 |
| Display          | 1024×768 or higher                                      |
| Architecture     | x86, x64, ARM, ARM64 depending on platform              |
| Network          | Optional for local media; recommended for network media |

Actual hardware requirements depend heavily on video resolution, codec, HDR format, hardware acceleration, add-ons, skins, and the type of media being played.

Kodi 22 also includes platform-specific improvements such as initial Windows ARM64 desktop support and enhanced video acceleration capabilities.
